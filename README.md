# 情報工学 QUIZ — 4択学習PWA

アップロードされた「2026 情報工学の基礎 第1回試験解説1・2」の内容から、**93問**の4択問題を作成した、iPhone対応の静的Webアプリです。フレームワークやサーバー・データベースは不要です。

## 主な機能

- ランダム10問 / 全93問 / 分野別出題（9分野）
- 問題順だけでなく、各問題の**4択選択肢の順番**も毎回シャッフル
- 回答後すぐに正誤・正解・解説を表示
- 間違えた問題が自動で復習リストに入り、その問題に正解するとリストから除外
- 結果画面から「今回間違えた問題だけ」を再挑戦可能
- 累計回答数・累計正答率・学習済み問題数・復習待ち・分野別進捗・最近の学習履歴
- `localStorage`に履歴・途中のクイズを保存
- ホーム画面追加（PWA）と、オンラインで一度開いた後のオフライン利用（Service Worker）

## iPhoneへの入れ方（おすすめ: GitHub Pages）

1. このフォルダ内のファイルと`icons`フォルダを、**配置を変えずに**GitHubのリポジトリにアップロードします。PDF本体は公開しないでください。
2. GitHubの **Settings → Pages → Build and deployment** で **Deploy from a branch** を選び、`main` / `(root)` を指定して **Save** します。
3. GitHub Pagesで発行された `https://...github.io/.../` をiPhoneの**Safari**で開きます。
4. Safariの**共有**（四角から上矢印）→ **ホーム画面に追加** → **追加** を選びます。
5. ホーム画面の「情報工学QUIZ」アイコンから起動できます。初回はネット接続して読み込んでください。

※GitHub Pagesは通常公開サイトです。問題は元資料を参考に短く言い換え、原PDFの複製や図版は入れていません。学内資料の転載・公開ルールを確認してから公開してください。公開せずに利用するなら、学内のみのHTTPSサーバ等で配信してください。

## PCで動作確認

フォルダ内で次を実行し、`http://localhost:8000/` を開きます。

```bash
python -m http.server 8000
```

HTML単体でも概ね動作しますが、オフライン対応（Service Worker）やホーム画面追加には通常HTTPS配信が必要です。

## ファイル

- `index.html`: 画面構造・メタ情報
- `style.css`: iPhone向けデザイン
- `app.js`: クイズ・採点・復習・学習記録
- `questions.js`: 問題93問（出典ページ表記あり）
- `manifest.webmanifest`: PWA定義
- `sw.js`: オフライン用キャッシュ
- `icons/`: アプリアイコン

## 備考

資料①の3ページ目は設問の2進数が9桁に見える一方で、解答が「173 / AD」です。アプリでは、その解答と整合する8ビット表記「10101101」で作問しています。

保存された学習履歴は**この端末・サイトのブラウザ内だけ**に置かれ、送信されません。ブラウザのサイトデータを削除すると履歴も消えます。
